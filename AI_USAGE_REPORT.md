## Incorrect AI Output

The first version added a second teacher to every subject when the number of
teachers was greater than the number of subjects.

For example, when there were five subjects and ten teachers, it selected two
teachers for each subject.

This was not correct because the number of teachers does not decide how many
teachers should teach a subject.

## How I Found the Problem

I tested the application with five subjects and ten teachers.

I noticed that the application selected two teachers for each subject even
though I had not entered any requirement for team teaching or a second
teacher.

I checked the assignment rules and saw that teacher assignments should come
from the college administrator.

## How I Fixed the Problem

I removed the automatic second-teacher rule.

The application now uses the teacher-subject assignments entered by the
administrator.

A teacher is selected only when the administrator assigns that teacher to the
subject.

The scheduler also checks that the teacher is not assigned to two divisions
during the same day and period.
